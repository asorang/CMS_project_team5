# JSimpleCMS
동의대학교 응용소프트웨어공학부 자바프로그래밍(캡스톤) 실습프로젝트 (5조)

---
### 개발 환경
- inteliiJ IDEA 2026.1.1 (2026.3.1)
- OpenJDK 17

### 사용된 외부 라이브러리 및 리소스
- 라이브러리
  - Gson (JSON 파싱 및 빌드) : https://github.com/google/gson
  - OSHI (하드웨어 정보 파싱) : https://github.com/oshi/oshi
- 리소스 (글꼴 및 이미지)
  - Material Icons (Manager 버튼) : https://fonts.google.com/icons
  - Windows 95 Icon Archive (Agent 트레이아이콘) : https://win98icons.alexmeub.com/
  - Pretendard Variable (글꼴) : https://cactus.tistory.com/306
